## Strategy definitions

- **`tsmom_4h`** — The task fixes 4h bars, 30-day return direction, EMA(50) slope agreement, 2×ATR(14) initial stop, no fixed TP, ExitPolicy trailing, and max hold 3 days. On 4h bars, 30 days = 180 completed candles; define return as `close[t]/close[t-180]-1` and EMA slope as `EMA50[t]-EMA50[t-1]`, using closed candles only. Moskowitz, Ooi & Pedersen document time-series momentum over 1–12 months (and a 12-month portfolio rule); therefore 30-day/4h + EMA confirmation is a task-specific adaptation, not their original rule. ATR smoothing and zero/equality handling are unspecified; make those explicit in the manifest (standard Wilder ATR(14), return/slope must be strictly positive/negative, equality=no signal are defensible defaults). Source: [paper PDF (NYU Stern/Pedersen)](https://w4.stern.nyu.edu/facdir/lpederse/papers/TimeSeriesMomentum.pdf).

- **`turtle_55`** — Task fixes 55-bar entry, 20-bar opposite extreme exit, 4h bars, STOP order, 2×ATR(20) stop and a time stop. Use prior completed bars only: entry trigger at max(high[t-55:t]) / min(low[t-55:t]); exit on close/breach of the prior 20-bar opposite extreme. A 4h bar-count adaptation means 55 bars = 9d 4h and 20 bars = 3d 8h, not the original daily Turtle horizons. The 55-day entry / 20-day exit pairing is the original System 2 configuration; 2×ATR(20) matches the canonical Turtle 2N initial stop when N is the 20-day ATR; the 4h bar adaptation and added time stop are implementation choices, and time-stop duration is unspecified. Source: [original rules text, *The Complete TurtleTrader* excerpt](https://www.tradingwithrayner.com/wp-content/uploads/2014/11/OriginalTurtleRules.pdf).

- **`vol_squeeze_breakout`** — Task fixes 1h, Bollinger-inside-Keltner squeeze, STOP beyond squeeze range, opposite range-side stop, 2R TP. Standard indicator defaults: BB(20, 2 SD); KC(20, 1.5 ATR) is a commonly documented TTM setting, but Carter's original “The Squeeze” used default Keltner 20/1.5 and BB 20/2; sources differ on original vs modern KC formula. Explicitly choose KC basis/smoothing (practical default EMA(20) ± 1.5×Wilder ATR(20)); define range as highest high/lowest low over consecutive squeeze-on bars, then trigger just beyond those levels. Ambiguities: whether to enter on squeeze-off or range breakout, whether squeeze may last any duration or capped, and tick buffer for STOP. Carter's squeeze itself is the BB bands wholly inside KC; original write-up says breakout signal as BB returns outside KC with 12-period momentum oscillator direction. Task's range breakout omits that momentum filter and is a distinct unproven variant. Sources: [Carter, CBOT article PDF](https://www.dormantrading.com/TraderTools/CBOTtheMarketplaceforActiveTraders.pdf); [Simpler Trading overview](https://www.simplertrading.com/blog/trading-tips-strategies/how-to-use-the-ttm-squeeze).

## Binance public ticker24hr schema / universe

For USDⓈ-M perps use `GET https://fapi.binance.com/fapi/v1/ticker/24hr` (no `symbol` returns an array; request weight 40). Relevant ticker fields include `symbol`, `quoteVolume` (string; quote-asset volume), plus price/volume timestamps. Parse `quoteVolume` as decimal; with `quoteAsset == USDC`, the $20M floor can be applied to USDC quote turnover. Pair with `GET /fapi/v1/exchangeInfo`; filter `status == TRADING`, `contractType == PERPETUAL`, `quoteAsset == USDC`, and preserve BTCUSDC/ETHUSDC explicitly if they meet the contract constraints. Ticker response itself does not establish perp status or quote asset. Sources: [official 24hr ticker docs](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/24hr-Ticker-Price-Change-Statistics); [official exchange-info docs](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Exchange-Information).
